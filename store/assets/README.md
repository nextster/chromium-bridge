# Store Assets

- `icon-source.svg` is the deterministic source for the extension icons.
- `promo-small-source.svg` is the deterministic source for the required promotional image.
- `promo-small-440x280.png` is the rendered promotional image uploaded to the Store dashboard.

The exact 16, 32, 48, and 128 pixel PNG icons live under `extension/icons`. Regenerate PNGs with `rsvg-convert`; do not replace them with fabricated or AI-generated artwork.

A real 1280x800 or 640x400 product screenshot must still be captured from the final Store-ID build after popup consent. Do not replace it with a fabricated UI mockup.
